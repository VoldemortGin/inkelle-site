Inkelle 使用指南 · 第 03 章 · 对应 App v1.6

页面与文档

一篇笔记可以有很多页。本章讲清楚怎么翻页、加页、管理和跳转，怎么用缩略图 / 大纲 / 书签快速定位，以及连续滚动、纸张尺寸、纸张模板、参考面板、演示模式和版本历史这些进阶功能——目标是让你在一本厚笔记里也能来去自如。

很多功能都在画布右上角的 ⋯ 菜单（"更多选项"）里，下面会逐一指出入口。

多页导航

翻页和加页的控件在画布的翻页栏里（iPad 宽屏在顶栏，iPhone 在紧凑底栏）：

  • 上一页 / 下一页：点左右箭头翻页。已在首页时"上一页"变灰，末页时"下一页"变灰。
  • 页码：中间显示"当前页 / 总页数"，比如 3 / 8。
  • 添加页面：点加号，在当前页之后插入一页新页（继承当前页的纸张尺寸与方向设置）。

小提示：新页会紧跟在你当前所在页的后面，而不是永远加到最后——想在某页后插页，先翻到那一页再点添加。

管理页面

需要整理页序、批量跳转或删页时，用 管理页面。

点按 ⋯ 菜单 → 管理页面，弹出列表，每行是一页的缩略图 + "第 N 页" + 该页模板名，当前页右侧有对钩：

  • 跳转：点任一行，关闭面板并跳到那一页。
  • 重排：按住行右侧拖动手柄上下拖，调整页序（拖完自动重新编号）。
  • 删除：向左滑动某一行删除。
  • 复制页面：长按某一行，选 复制页面（详见下文）。

小提示：一本笔记至少要保留 1 页，所以当只剩最后一页时无法再删。

复制页面：会在原页后面插入一份深拷贝，连同笔迹、纸张尺寸 / 方向 / 旋转角度、图片、便签、公式、链接、文本框一起复制。注意：书签、大纲标题和版本历史不会带到副本上。

全部页面（网格总览）

想一眼看完整本笔记、或一次删多页时，用 全部页面 网格视图。

点按 ⋯ 菜单 → 全部页面，所有页以缩略图网格铺开，当前页有高亮描边，加过书签的页右上角有书签徽标：

  • 跳转：直接点某页缩略图跳过去。
  • 多选删除：点右上角 选择 进入多选，勾选要删的页，点底部 删除所选 (N)，确认后删除。删除不可撤销，且删完至少要剩 1 页。
  • 复制页面：长按某页缩略图选 复制页面。

页面缩略图条

想边写边快速跳页，又不想离开当前页时，打开顶部的缩略图条。

点按 ⋯ 菜单 → 页面缩略图（这是个开关）。画布顶部会出现一条横向缩略图：

  • 点任一缩略图跳到该页，当前页自动居中并高亮。
  • 条尾的虚线 "+" 按钮 添加 一页新页。

再次点菜单里的 页面缩略图 可收起这条。它只负责跳页和加页，不能删页或重排。

导航侧栏（缩略图 / 大纲）

⋯ 菜单 → 导航 会在画布左侧滑出一个侧栏浮层，不遮挡你正在写的页面。侧栏顶部有两个分段标签：

  • 缩略图：竖排的整页缩略图列表，点击跳转，加过书签的页有书签徽标。
  • 大纲：显示这本笔记的大纲与书签（见下一节）。

小提示：关闭导航侧栏不会改变你当前所在的页，可以放心随时开合。

大纲与书签

书签帮你把重点页"钉"住随时回跳；大纲给你一份全篇结构索引。两者都在 ⋯ 菜单 → 大纲（或导航侧栏的"大纲"标签）里。

为当前页加书签：

  • 在大纲面板顶部，点 加书签（加过后显示 已加书签，再点即取消）。
  • 加书签后下方会出现 大纲标题 输入框，给这一页起个名字，方便日后辨认。
  • 也可直接用 ⋯ 菜单 → 为本页添加书签 / 移除书签。

大纲面板里有两个分区：

  • 大纲：如果是从 PDF 导入的笔记，这里按 PDF 自带的目录层级展开；普通手写笔记则用每页识别出的首行文字作为标题提示。
  • 书签：列出所有加过书签的页，点任一条即跳转；向左滑动某条可 移除 该书签。还没有书签时会提示"为页面加书签，即可在此快速跳转"。

连续滚动

默认是一页一页翻的单页模式。打开 连续滚动 后，所有页会像长卷一样竖向堆叠，可以直接上下滚动浏览、跨页书写。

点按 ⋯ 菜单 → 连续滚动（开关）即可切换，这个偏好会被记住。滚动到底部有 添加 页脚可加页。

小提示：连续滚动模式下有几项功能暂不可用，需要它们时请切回单页模式：套索圈选转 AI（抽认卡 / 数学 / 润色）、套索手写转文字、放大书写、文档内查找、笔迹回放、Apple Pencil 双击切换、橡皮擦。此外，页数很多的长笔记在这个模式下开销较大，可能略有卡顿。

纸张尺寸与页面旋转

纸张尺寸：点按 ⋯ 菜单 → 页面尺寸，从 默认 / A4 / Letter 中选一种，并可单独打开 横向 开关切成横版。（想要竖版就把"横向"关掉——没有单独的"纵向"选项。）新加的页会继承当前页的尺寸和横向设置。

旋转页面：点按 ⋯ 菜单 → 旋转页面，每点一次页面顺时针转 90 度，循环 0° → 90° → 180° → 270° → 0°。屏幕显示和导出的 PDF 都会遵循这个角度。

纸张模板

模板决定页面背景（横线、方格、康奈尔笔记等）。点按画布工具栏的 纸张模板 打开选择器，选好后应用到当前页。模板按 基础 / 学习 / 计划 / 音乐 四类组织。

内置模板（8 种）：

分类模板
基础空白、横线、方格、点阵
学习康奈尔笔记
计划待办清单、周计划
音乐五线谱

预设版式（7 种，带现成分栏结构）：

分类版式
学习SWOT 分析、问答学习笔记、抽认卡
计划习惯打卡表、复习计划、每日时间表
基础点阵+留边

我的模板（自定义导入）：在"我的模板"分区点 导入模板，选一份 PDF、PNG 或 JPEG 作为页面背景。长按自定义模板可 删除——删除后，用过它的页会恢复为空白背景，你的笔迹和内容会保留。

AI 生成模板：如果你已配置好 AI，"我的模板"分区旁会有 AI 生成 按钮。

  1. 点 AI 生成，打开 AI 生成模板 面板。
  2. 在 描述你想要的版式 里用大白话描述，比如"考研数学错题本，左边写题目，右边写解析，底部留一栏记易错点"。（面板里还有"三栏对比笔记，等分成三列""顶部标题区，下面是带横线的康奈尔笔记"等示例可直接点用。）
  3. 点 生成模板，在 预览 里查看效果，满意就点 保存为模板。生成的模板会存进"我的模板"并应用到当前页；不满意可换个描述重试。

参考面板

一边写笔记、一边对照另一本笔记时用它。

点按 ⋯ 菜单 → 参考面板，画布右侧分屏浮出一栏。顶部点 选择笔记 选一本要参考的笔记，底部 上一页 / 下一页 翻阅它的内容。用完点 关闭参考面板（菜单项也会变成"隐藏参考面板"）。

小提示：参考面板是只读的——只显示对照笔记的模板背景和手写墨迹，不能在里面编辑，也不会显示对方页面上的文本框、图片、公式等标注。你选的参考笔记会被记住，下次打开面板还在。

演示模式

把笔记投到大屏讲解时用它。点按 ⋯ 菜单 → 演示模式，进入全屏黑底展示：

  • 翻页：左右滑动，或点底部箭头。（在 Mac 上可用左右方向键翻页、Esc 退出。）
  • 激光笔：点底部的圆点按钮开启，拖动即可用红点圈画重点（Mac 上跟随鼠标）。
  • 点右下角关闭按钮退出。

小提示：演示模式只渲染模板背景和手写墨迹，页面上的文本框、图片、公式、便签、链接等标注不会显示，页面旋转也会被忽略。若讲解内容依赖这些元素，建议改用导出 PDF 来投屏。

版本历史

写错了想回到之前的样子？Inkelle 会自动为每一页留存历史快照。

点按 ⋯ 菜单 → 版本历史，看到按时间倒序排列的快照列表，每条显示缩略图、日期时间和大小：

  • 预览：点眼睛图标，放大查看某个版本的笔迹。
  • 恢复：点行内 恢复（或预览页里的 恢复此版本），当前画布会被替换为该版本。
  • 删除：向左滑动某条删除。

小提示：快照在每次保存绘图时自动创建，每页最多保留 20 个；超过后会从最旧的开始自动清理。所以版本历史适合"最近的反悔"，不要当作长期归档。
