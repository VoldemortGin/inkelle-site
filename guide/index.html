Inkelle 使用指南

欢迎使用 Inkelle——一款以 Apple Pencil 手写为核心、内建 AI 与间隔重复学习系统的笔记 App。这套指南按功能分章，帮你从零上手到用满每一项能力。建议第一次使用先读《快速上手》，之后按需查阅对应章节。

01

快速上手

界面导览、创建笔记本与笔记、iPad / iPhone / Mac 三种形态的差异

02

书写与画布

笔类型 / 颜色 / 粗细 / 画笔预设、挤压唤出预设盘、橡皮擦、直尺、形状识别、套索选择、放大书写、专注模式

03

页面与文档

多页管理、缩略图 / 大纲 / 书签、连续滚动、纸张尺寸与旋转、纸张模板（内置 / 自定义 / AI 生成）、参考面板、演示模式、版本历史

04

插入内容

文本框、公式（LaTeX）、便签遮盖、链接、图片 / 相机 / 扫描文稿、贴纸

05

录音与课堂

录音、逐词转写与回放、录音↔笔迹同步、AI 课堂纪要、导出讲解视频

06

AI 助手

端上免费引擎与 DeepSeek（自带 Key）、隐私授权、总结 / 问答 / 数学 / 抽认卡 / 测验 / 润色、套索转 AI、快捷指令

07

学习系统

抽认卡、复习与评分、SM-2 / FSRS 调度、到期复习、锁屏 / 小组件 / 灵动岛评分、考试模式、学习仪表盘、薄弱点修复、知识图谱、复习提醒

08

搜索与整理

全文与手写搜索、文档内查找、标签、智能文件夹、文件夹层级、批量操作、锁定笔记本、笔记本外观

09

同步 · 备份 · 导入导出

iCloud 同步、自动 / 手动备份、导出 PDF / PNG / SVG / 文本 / Anki / 学习网页 / 视频、共享笔记本、打印、导入文档

10

订阅与购买

免费额度、Inkelle Pro 年度订阅与永久买断、恢复购买、兑换优惠码

11

设置速查与常见问题

设置项一览、故障排查（同步不显示 / AI 不可用 / 录音无声等）

阅读约定

  • ⋯ 菜单指画布右上角的"更多选项"菜单，很多进阶功能都在这里。
  • 小提示框里是省时间的技巧。
  • 文中的功能名称（如"套索""便签""参考面板""课堂纪要"）与 App 内的中文文案保持一致。
