搜索与整理

笔记越写越多，找得到、理得清才用得顺手。这一章讲怎么在整个资料库里搜到想要的内容，怎么用标签、智能文件夹、文件夹层级把笔记归置好，以及锁定、外观、回收站这些整理相关的功能。

全库搜索

侧边栏顶部有一个搜索框，占位文字是「搜索笔记本和笔记内容」。在这里输入关键词，会同时搜三类内容：

  • 笔记本标题
  • 笔记标题
  • 笔记里的文字——包括手写识别（OCR）出的文字、导入 PDF 的文本层、以及录音的转写文字

搜索结果每一条右侧都带一个来源徽标，告诉你是哪儿命中的：

徽标含义
标题命中的是笔记标题
手写命中的是手写识别出来的文字
PDF命中的是导入 PDF 里的文字
录音命中的是录音转写的文字

命中手写、PDF 或录音时，结果下方还会显示一段高亮的摘录，让你先扫一眼上下文再决定要不要点开。点开一条结果，会直接跳到第一处命中的那一页；如果只是标题命中，则从第 1 页打开。

小提示：手写搜索依赖后台的文字识别。刚写完的笔记可能要等几秒识别完成才能被搜到；如果一直搜不到旧笔记里的手写内容，可以到「设置 › 数据管理 › 重建手写索引」重新扫一遍（见第 9 章）。

小提示：iPad 上按 Cmd+F（外接键盘）可以直接把光标定位到侧边栏搜索框。iPhone 上则有独立的「搜索」标签页。

笔记本内搜索

打开一个笔记本后，右上角的放大镜按钮会展开一个搜索框（占位文字是「在〈笔记本名〉中搜索」）。这个搜索只匹配笔记标题，用来在一本笔记里快速定位某一篇，不会搜正文或手写内容。要搜内容，请用上面的全库搜索。

在本文档中查找

在画布里翻某一篇长笔记时，想定位到写了某个词的那一页，用「在本文档中查找」：

  1. 打开笔记，从画布右上角 ⋯ 菜单（更多选项）里进入文档内查找。
  2. 输入关键词，Inkelle 会逐页比对每一页的识别文字，并显示匹配总数。
  3. 用「上一个匹配」「下一个匹配」在命中页之间跳转，到头会自动绕回。

标签

标签是跨笔记本的横向分类。给不同笔记本里的笔记打上同一个标签（比如「期中」「实验报告」），就能一次性把它们聚到一起。

新建与指派标签

  1. 长按一张笔记卡片，在弹出菜单里选「管理标签」。
  2. 在底部输入框里填标签名称，选一个颜色，点加号即可新建，并会直接指派给当前这篇笔记。
  3. 已有的标签会以彩色 chip 列出，点一下 chip 就能给当前笔记指派或取消指派（选中的带对勾）。

管理已有标签

在「管理标签」面板里长按某个标签 chip，会弹出管理菜单：

  • 重命名——改标签名字。
  • 更改颜色——从 8 种颜色里重新选。
  • 合并到…——把这个标签下的所有笔记并到另一个标签，然后删除原标签。整理重复标签时很有用。
  • 删除标签——从所有笔记上移除这个标签（确认后不可撤销，但笔记本身不会被删）。

按标签筛选

侧边栏有一条横向的标签筛选栏，最前面是「全部」，后面是正在使用中的标签。点一个标签就只看它下面的笔记，再点一次同一个标签取消筛选。一次只能选一个标签。

智能文件夹

智能文件夹不是真的文件夹，而是一组「筛选条件」——笔记只要符合条件就会自动出现在里面，不用手动搬。它在侧边栏「智能文件夹」区。

内置智能文件夹

名称收录范围
全部笔记所有笔记
有标签的笔记至少打了一个标签的笔记
本周创建最近 7 天内创建的笔记
收藏标了收藏的笔记

每个都在侧边栏实时显示数量。

新建自定义智能文件夹

点「智能文件夹」区标题右侧的「+」，打开规则编辑器：

  1. 起一个名称，可选一个图标。
  2. 选组合方式：「满足全部」（所有条件都成立）或「满足任一」（成立一条即可）。
  3. 点「添加条件」，逐条设置。可加多条，左滑删除。至少一条条件、且填了名称才能保存。

可用的条件字段：

条件字段怎么填
标签包含从下拉里选一个标签
标题含关键词输入关键词
正文含关键词输入关键词（匹配标题、正文与识别文字）
创建时间最近 N 天（1–365）
修改时间最近 N 天
已收藏是 / 否
含录音是 / 否
是 PDF是 / 否
含公式是 / 否
所属笔记本从下拉里选一个笔记本

建好的智能文件夹长按可「编辑」或「删除」。

小提示：想要「本月错题本里带公式、还没掌握的题」这类组合视图？用「满足全部」，叠加「所属笔记本 = 错题本 + 含公式 = 是 + 修改时间 = 最近 30 天」就能拼出来。条件是活的，笔记一变动就自动进出。

文件夹层级

笔记本可以无限嵌套子笔记本，像文件夹一样组织。

  • 新建子笔记本：长按一个笔记本，选「新建子笔记本」。
  • 移动到…：长按笔记本选「移动到…」，从列表里挑目标笔记本（不会列出它自己和它的后代，避免套环）。
  • 移到顶层：如果笔记本当前有父级，菜单里会出现「移到顶层」，一步把它提到最外层。
  • 把笔记拖进笔记本：直接把一张笔记卡片拖到侧边栏的某个笔记本上，笔记就归到那本里。

小提示：调整笔记本之间的父子层级要用「移动到…」菜单——目前不支持在侧边栏直接把一个笔记本拖到另一个笔记本上重组层级。

批量操作

在一本笔记本里要一次处理多篇笔记时：

  1. 打开笔记本，点右上角「选择」。
  2. 逐张点选笔记（卡片上出现勾选圈）。
  3. 底部操作栏有三个批量操作：
    • 移动——把所选笔记一起移到另一个笔记本。
    • 导出——把每篇笔记各导出成一个 .inkelle 文件，一起走系统分享面板。
    • 删除——把所选笔记一起移到回收站（软删除，确认后执行）。

小提示：批量选择只在单个笔记本内可用，智能文件夹和搜索结果里没有。目前也没有「全选」，以及批量打标签/收藏/锁定。

锁定笔记本与笔记

对含隐私内容的笔记，可以用 Face ID / Touch ID 锁起来。笔记本和单篇笔记都能锁：

  • 锁笔记本：长按侧边栏的笔记本，选「锁定」。
  • 锁单篇笔记：长按笔记卡片，选「锁定」。

锁定后：

  • 打开被锁的笔记本或笔记，都需要先通过 Face ID / Touch ID 验证（设备没有生物识别时会回退到设备密码）。
  • 解锁或移除锁本身也要先验证，别人拿到设备也去不掉锁。
  • 被锁的项目在卡片和列表里只显示一个锁的占位图，不露缩略图。
  • 在搜索和系统 Spotlight 里，被锁的项目只按标题匹配，其手写内容、录音转写都不会被搜到，隐私内容不外泄。

笔记本外观

给笔记本换个封面颜色、封面图或图标，一眼就能认出。长按侧边栏的笔记本，菜单里有「图标」和「封面」两个入口，都会打开外观设置面板，可改三样：

  • 封面图——点「选择照片」从相册挑一张图当封面，也可以「移除封面图」。
  • 颜色——从预设色环里选一个书脊/封面颜色。
  • 图标——从图标网格里选一个 SF Symbol，或选「无图标」。

此外，打开笔记本后右上角「⋯」里的「笔记本设置」，可以改这本笔记的默认页模板和封面颜色（这里不含图标和封面图）。

排序、视图与收藏

打开笔记本后，工具条上：

  • 排序：左侧下拉菜单，可选「最近修改」「名称」「创建时间」。
  • 网格 / 列表：右上角按钮切换两种视图，选择会在全 App（含智能文件夹）记住。
  • 只看收藏：工具条上的星形按钮，只显示收藏的笔记。

收藏一篇笔记：长按笔记卡片，选「收藏」（再长按可「取消收藏」）。

侧边栏还有一个「最近打开」区，按你最近打开的顺序列出最多 10 篇笔记，方便接着上次继续（仅在没有搜索时显示）。

回收站

删除的笔记本和笔记不会立刻消失，而是先进「回收站」（侧边栏底部）。

  • 保留 30 天：删除项保留 30 天，过期后自动清除。
  • 分区：回收站分「笔记本」和「笔记」两段；删掉的笔记本里的笔记不会重复列出。
  • 删除时间：每项显示「今天删除」或「N 天前删除」。
  • 恢复：点某项的「恢复」，笔记 / 笔记本（连同其中所有笔记）都会回到原位。
  • 永久删除：点「永久删除」彻底删掉某项（删笔记本会二次确认）。
  • 清空回收站：顶部「清空回收站」按钮，确认后永久删除回收站里的全部内容。

小提示：永久删除和清空回收站都无法恢复，动手前确认一下。删错了但还没永久删除的，30 天内都能从回收站找回来。
